## 🐛 Problems & Solutions
**Problem Description:**
1. When creating the `notes` folder, I used the wrong path and was treating the system user folder as the code repository.
2. I had deleted the remote repository earlier but forgot to delete the old local folder.
3. `git clone` threw an error, and I was still in `D:\Code` instead of inside the project folder.
4. Before the local folder was successfully linked to the new remote repository, Git reported that the current directory was not a Git repository.

**Solution Process:**
1. Noticed the wrong path, then switched back to the correct repository path and successfully created the `notes` and `templates` folders.
2. Completely deleted the old local folder, then continued.
3. Deleted the local folder and re-cloned the repository.
4. `cd` into the project folder so that Git commands run inside the Git repository.

**Final Solution:**
- Always confirm the current working directory before creating files or running Git commands.
- Remove the stale local folder before cloning again to avoid conflicts.
- Run `git clone`, then `cd` into the project folder before any further Git operations.
