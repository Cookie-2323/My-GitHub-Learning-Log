## 🐛 Problems & Solutions
**Problem Description:**
1. When creating the `notes` folder, I used the wrong path and was treating the system user folder as the code repository.
2. I had deleted the remote repository earlier but forgot to delete the old local folder.
3. `git clone` threw an error, and I was still in `D:\Code` instead of inside the project folder.
4. Before the local folder was successfully linked to the new remote repository, Git reported that the current directory was not a Git repository.
5. When I pushed the new feature branch for the first time, `git pull` reported "no tracking information for the current branch".
6. After merging the Pull Request on GitHub, my local `main` was still on the old commit and did not contain the merge.
7. Deleting the local branch with `git branch -d` failed because Git thought the branch was not fully merged yet.

**Solution Process:**
1. Noticed the wrong path, then switched back to the correct repository path and successfully created the `notes` and `templates` folders.
2. Completely deleted the old local folder, then continued.
3. Deleted the local folder and re-cloned the repository.
4. `cd` into the project folder so that Git commands run inside the Git repository.
5. Used `git push -u origin feature/add-mood-block` to push the branch and set the upstream tracking branch at the same time.
6. Ran `git switch main` and then `git pull` to fast-forward the local `main` and receive the merge commit.
7. Checked `git branch` to confirm the work was already merged, then deleted the local branch with `git branch -d` instead of `-D`.

**Final Solution:**
- Always confirm the current working directory before creating files or running Git commands.
- Remove the stale local folder before cloning again to avoid conflicts.
- Run `git clone`, then `cd` into the project folder before any further Git operations.
- The full advanced Git flow: `git switch -c feature/add-mood-block` → edit files → `git add .` → `git commit -m "..."` → `git push -u origin feature/add-mood-block` → open a Pull Request on GitHub → merge into `main` → delete the remote branch → `git switch main` + `git pull` → `git branch -d feature/add-mood-block`.
- After merging a Pull Request, always switch back to `main` and `git pull` before deleting the branch.
